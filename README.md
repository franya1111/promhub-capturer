# 🛰️ PromHub Capturer

**Chrome-розширення, яке автоматично перехоплює запити my.prom.ua і зберігає їх як шаблони для вашої панелі promv2.**

Після налаштування — кнопки «Редагувати товари», «Змінити оплату», «📎 Прив'язати чек» в модалці обробки замовлення на promv2 працюють **автоматично**. Без ручного копіювання cURL з DevTools.

---

## 📋 Що це і навіщо

### Проблема

Ви маєте панель обробки замовлень на promv2. Там є кнопки:
- ✎ Редагувати товари → зберегти на Prom.Ua
- ✎ Змінити спосіб оплати
- 📎 Прив'язати чек Checkbox.ua

Але вони не працюють, бо публічне API Prom.Ua **не підтримує** ці операції. Працює тільки через сесію кабінету my.prom.ua — треба скопіювати cURL-запит з DevTools і зберегти як шаблон. Це незручно.

### Рішення

Це Chrome-розширення **само ловить** потрібні запити на my.prom.ua, показує вам спливаючу панель і пропонує зберегти шаблон в один клік.

### Чи можна встановити на інший комп'ютер?

**ТАК!** Розширення не залежить від сервера promv2. Воно може стояти:
- ✅ На вашому робочому ноутбуці, де ви обробляєте замовлення на my.prom.ua
- ✅ На комп'ютері менеджера, який працює з my.prom.ua
- ✅ На домашньому комп'ютері
- ✅ На будь-якому комп'ютері з Chrome

Розширення просто відправляє дані по HTTPS API на ваш сервер promv2. Сам сервер promv2 може стояти де завгодно — на VPS, хостингу, Docker-контейнері.

## 🚀 Покрокова інструкція для початківців

### Крок 1. Підготувати сервер promv2 (5 хвилин)

Це треба зробити **один раз** на сервері, де стоїть ваша панель promv2.

#### 1.1. Згенерувати секретний ключ

Зайдіть на сервер promv2 по SSH:
```bash
ssh user@your-server
cd /var/www/promv2.franya.dev   # або де у вас promv2
```

Виконайте команду:
```bash
php -r "echo bin2hex(random_bytes(16)), PHP_EOL;"
```

Вона виведе щось типу:
```
3a8f4c2b9e1d7a5f8c4b6e2d9a1f3c5e
```

**Скопіюйте цей рядок** — це ваш секрет. Не показуйте його нікому.

#### 1.2. Додати секрет в конфіг promv2

Відкрийте файл `config.local.php`:
```bash
nano config.local.php
```

В кінець файлу додайте рядок (після `AUTH_SESSION_LIFETIME`):
```php
// === Chrome extension secret ===
define('CABINET_TEMPLATE_SECRET', '3a8f4c2b9e1d7a5f8c4b6e2d9a1f3c5e');
```

Замініть `3a8f4c2b9e1d7a5f8c4b6e2d9a1f3c5e` на ваш згенерований секрет.

Збережіть (Ctrl+O, Enter, Ctrl+X для nano).

#### 1.3. Перевірити, що endpoint працює

Відкрийте в браузері:
```
https://promv2.franya.dev/api/ajax_cabinet_template.php
```

Має показати JSON з помилкою типу:
```json
{"ok":false,"error":"Необхідна авторизація..."}
```

Якщо показує помилку 500 або щось інше — перевірте, що файл існує і має права на читання:
```bash
ls -la api/ajax_cabinet_template.php
chmod 644 api/ajax_cabinet_template.php
```

### Крок 2. Завантажити розширення на комп'ютер

Це робиться на комп'ютері, де ви працюєте з my.prom.ua.

#### Варіант А: Завантажити ZIP з GitHub

1. Відкрийте: https://github.com/franya1111/promhub-capturer
2. Натисніть зелену кнопку **«Code»** → **«Download ZIP»**
3. Розпакуйте ZIP в будь-яку теку (наприклад, `C:\promhub-capturer\` або `~/promhub-capturer/`)
4. В середині має бути файл `manifest.json`

#### Варіант Б: Через git

```bash
git clone https://github.com/franya1111/promhub-captcher.git
cd promhub-capturer
```

### Крок 3. Встановити розширення в Chrome

1. Відкрийте Chrome (або Edge / Brave / інший Chromium-браузер)
2. В адресному рядку введіть:
   ```
   chrome://extensions/
   ```
   і натисніть Enter
3. У правому верхньому куті знайдіть перемикач **«Режим розробника»** (Developer mode) — увімкніть його
4. З'явиться кнопка **«Завантажити розпаковане розширення»** (Load unpacked) — натисніть її
5. Виберіть теку, куди ви розпакували розширення (де лежить `manifest.json`)
6. Розширення з'явиться в списку з іконкою 🛰️

### Крок 4. Закріпити іконку розширення

1. Натисніть на іконку пазла 🧩 у правому верхньому куті Chrome
2. Знайдіть у списку **«PromHub Capturer»**
3. Натисніть на іконку **📌** (закріпити)
4. Тепер іконка 🛰️ завжди буде на панелі

### Крок 5. Налаштувати розширення

1. Клікніть по іконці 🛰️ на панелі Chrome
2. Відкриється вікно налаштувань

Заповніть поля:

**«Сервер promv2 (URL api endpoint)»** — за замовчуванням:
```
https://promv2.franya.dev/api/ajax_cabinet_template.php
```
Якщо ваш promv2 на іншому домені — замініть.

**«Secret»** — вставте ваш секрет з кроку 1.2 (32 символи, які ви згенерували)

3. Натисніть **«💾 Зберегти налаштування»**
4. Натисніть **«🧪 Перевірити з'єднання»**
5. Має з'явитися зелений блок:
   ```
   ✓ З'єднання OK. Сервер час: 2025-10-17 12:34:56
   ```

Якщо червона помилка — перевірте:
- Чи правильно введений Secret (має збігатися з config.local.php)
- Чи доступний сервер promv2
- Чи нема пробілів на початку/в кінці Secret

### Крок 6. Захопити шаблони

Тепер відкрийте **my.prom.ua** і виконайте дії — розширення автоматично їх перехопить.

#### 6.1. Шаблон редагування товарів

1. Відкрийте https://my.prom.ua → будь-яке замовлення
2. Знайдіть блок товарів → натисніть «Редагувати»
3. **Додайте один товар** або змініть кількість → збережіть
4. Справа на сторінці з'явиться панель PromHub з карточкою:
   ```
   🟡 РЕДАГУВАННЯ ТОВАРІВ   [POST]
   URL: /api/v1/orders/12345...
   № замовлення: 1234567890
   Аккаунт: reohimik
   Захоплено: 14:32:15
   [💾 Зберегти шаблон товарів] [Відхилити]
   ```
5. Натисніть **«💾 Зберегти шаблон товарів»**
6. Має з'явитися зелений блок:
   ```
   ✓ Шаблон items збережено для акаунта reohimik
   ```

#### 6.2. Шаблон зміни оплати

1. На сторінці того ж замовлення
2. Знайдіть блок оплати → змініть спосіб оплати (напр., з «Готівка» на «Visa/Mastercard»)
3. Збережіть
4. Справа з'явиться карточка:
   ```
   🔵 ЗМІНА СПОСОБУ ОПЛАТИ   [POST]
   № замовлення: 1234567890
   ID оплати: 8197515
   Аккаунт: reohimik
   [💾 Зберегти шаблон оплати] [Відхилити]
   ```
5. Натисніть **«💾 Зберегти шаблон оплати»**

#### 6.3. Шаблон прив'язки чека

1. На сторінці замовлення знайдіть поле «Чек» / «Фіскальний чек»
2. Вставте посилання на чек з Checkbox.ua (напр., `https://check.checkbox.ua/abc-123`)
3. Збережіть
4. З'явиться карточка:
   ```
   🟢 ПРИВ'ЯЗКА ЧЕКА   [POST]
   Посилання чека: https://check.checkbox.ua/abc-123
   Аккаунт: reohimik
   [💾 Зберегти шаблон чека] [Відхилити]
   ```
5. Натисніть **«💾 Зберегти шаблон чека»**

### Крок 7. Перевірити, що все працює

1. Відкрийте вашу панель promv2: https://promv2.franya.dev/
2. Зайдіть у будь-яке замовлення → відкриється модалка обробки
3. Натисніть **«✎ Редагувати»** у блоці товарів → змініть → «💾 Зберегти на Prom.Ua»
4. Тепер має працювати! (Раніше — помилка, тепер — успішно)

Те саме з кнопками **«✎ Змінити оплату»** і **«📎 Прив'язати чек»**.

## 🔄 Чи треба повторювати захоплення?

**НІ**, шаблони зберігаються назавжди (поки не зміниться сесія my.prom.ua).

**АЛЕ** — якщо ви:
- Вийшли з my.prom.ua і знову зайшли → сесія може оновитися, шаблон треба перезахопити
- Chrome скинув cookie my.prom.ua → те саме
- Пройшов ~30 днів → сесія протухла (my.prom.ua саме сбрасує сесії)

**Ознака протухлої сесії:** в модалці обробки замовлення з'являється помилка:
```
✗ Кабінет: HTTP 401 — сесія кабінету протухла або CSRF-токен застарів.
```

**Рішення:** повторіть крок 6 — відкрийте my.prom.ua, виконайте дію, розширення знову запропонує зберегти шаблон.

## 🛡️ Безпека

### Що розширення має доступ до:

- ✅ Тільки домени `my.prom.ua`, `my.bigl.ua`, `my.satu.kz`, `my.deal.by` (для перехоплення запитів)
- ✅ Домен вашого сервера promv2 (напр., `promv2.franya.dev`) — для відправки шаблонів
- ✅ Chrome storage — для збереження налаштувань (server URL + Secret)
- ❌ НЕ має доступу до інших сайтів
- ❌ НЕ передає cookie my.prom.ua кудись, окрім вашого власного сервера promv2

### Що зберігається на сервері promv2

Розширення зберігає повний cURL-запит з my.prom.ua (вкл. cookie сесії) на сервері promv2 в БД `app_settings` з ключем `prom_cabinet_{type}_{account_id}`.

**Це необхідно** — сервер promv2 використовує цей cURL для повторення запитів (фолбек через сесію кабінету). Cookie дає доступ **тільки до вашого власного кабінету продавця** — ніхто сторонній не може ним скористатися без доступу до вашого сервера promv2.

### Якщо Secret потрапив до сторонніх

Якщо хтось дізнався ваш Secret — згенеруйте новий:
1. На сервері promv2 виконайте `php -r "echo bin2hex(random_bytes(16)), PHP_EOL;"`
2. Замініть `CABINET_TEMPLATE_SECRET` в `config.local.php` на новий
3. В розширенні: клікніть 🛰️ → вставте новий Secret → Зберегти

## 🐛 Усунення несправностей

### Розширення не показує панель на my.prom.ua

1. Перевірте, що розширення увімкнене в `chrome://extensions/`
2. Перезавантажте сторінку my.prom.ua (Ctrl+R)
3. Натисніть F12 → вкладка Console — має бути напис:
   ```
   [PromHub Capturer] ініціалізовано на my.prom.ua
   ```
4. Якщо нема — перевірте, що URL відповідає патерну (`my.prom.ua`, а не `prom.ua` без `my.`)

### «✗ Не налаштований Secret»

1. Клікніть по іконці 🛰️ на панелі Chrome
2. Вставте `CABINET_TEMPLATE_SECRET` з `config.local.php` сервера promv2
3. Збережіть

### «✗ З'єднання» тест не проходить

- Перевірте, що `https://promv2.franya.dev/api/ajax_cabinet_template.php` доступний (відкрийте в браузері)
- Перевірте, що `CABINET_TEMPLATE_SECRET` однаковий в `config.local.php` і в налаштуваннях розширення
- Перевірте логи на сервері promv2: `tail -f logs/api.log`

### Шаблон збережено, але операція в модалці не працює

- Відкрийте `https://promv2.franya.dev/diagnose_order_edit.php?acc=АККАУНТ&order=ЗАМОВЛЕННЯ` — перевірте статус шаблону в секціях C, D, E
- Можливо сесія кабінету my.prom.ua протухла — повторіть крок 6 (захоплення)

### Панель з'являється, але «Зберегти» не працює

Відкрийте DevTools (F12) на my.prom.ua → вкладка Console → виконайте дію. Якщо є помилки — скиньте скріншот.

## ❓ Часті питання

### Чи можна встановити на Firefox?

Ні, розширення використовує Manifest V3 (Chrome стандарт). Firefox має свій формат. Якщо потрібно — можу адаптувати.

### Чи можна встановити на телефон?

Ні, Chrome на Android не підтримує розширення. На iPhone — тим більше. Використовуйте комп'ютер.

### Чи можна використовувати на кількох комп'ютерах?

**ТАК!** Встановіть розширення на скільки завгодно комп'ютерів. На кожному введіть:
- Той самий URL сервера promv2
- Той самий Secret

Усі шаблони будуть зберігатися на одному сервері promv2.

### Чи буде розширення працювати без доступу до інтернету?

Ні — потрібно з'єднання з my.prom.ua (для перехоплення запитів) і з сервером promv2 (для збереження шаблонів).

### Чи може розширення працювати з кількома магазинами?

**ТАК!** Якщо у вас кілька магазинів на Prom.Ua (reohimik, chemplanets, sklad1) — для кожного треба окремо захопити шаблон. Просто перемикайте акаунти в my.prom.ua і виконуйте дії — розширення збереже шаблон для кожного акаунта окремо.

### Чи змінює розширення поведінку my.prom.ua?

**НІ!** Розширення тільки читає запити — не модифікує їх. My.prom.ua працює як завжди. Просто після кожної дії з'являється панель з пропозицією зберегти.

### Що буде, якщо відключити розширення?

- Шаблони, які вже збережені на сервері promv2 — **залишаться**
- Перехоплення нових запитів — **не працюватиме**
- Робота модалки обробки замовлень на promv2 — **продовжить працювати** з уже збереженими шаблонами

Якщо щось не працює:

1. **Перевірте логи на сервері promv2:**

2. **Перевірте логи розширення:**
   - Відкрийте `chrome://extensions/`
   - Знайдіть PromHub Capturer → натисніть «деталі»
   - Натисніть «Service worker» — відкриється DevTools з логами

3. **Скиньте скріншот помилки + рядок з логу** — розберемось.
